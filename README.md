# Corrected academic website starter

This package uses explicit filenames so each page's role is clear. See `FILE-MAP.txt`.

## Publish on GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload the **contents** of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io/`.

## Personalize

- Replace every occurrence of `Your Name` in the HTML files.
- Replace bracketed text such as `[position]` and `[institution]`.
- Add your image to `assets/`, then update the image filename in `index.html`.
- Put PDFs in `documents/` and link to them with paths such as `documents/cv.pdf`.

`index.html` must keep that exact name because GitHub Pages uses it as the homepage.
